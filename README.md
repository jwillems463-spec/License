# R068 Distinction Checklist

A single-page, tickable checklist for the OCR Cambridge National in Enterprise and
Marketing, unit **R068 – Design a business proposal**, built against the *Secure Case*
set assignment (valid for the January and June 2027 series).

It covers all six tasks and all 60 marks, with the Mark Band 3 requirement for each
task, worked example bullets showing the shape of a top-band answer, and the exam
board's own definitions of the descriptor words the marking grids use.

## Publishing it as a web link

The page is a single self-contained `index.html` with no build step and no server
requirements. To serve it from GitHub Pages:

1. Merge this branch into `main`.
2. Go to **Settings → Pages** in this repository.
3. Under **Build and deployment**, set *Source* to **Deploy from a branch**, the
   branch to **main** and the folder to **/ (root)**, then press **Save**.
4. Wait a minute or two. The page will be live at:

   `https://jwillems463-spec.github.io/License/`

Anyone with that link can open it. No sign-in, no account.

## How the ticking works

Each student's ticks are saved in their own browser (`localStorage`), so the page
reopens where they left off on that device. Ticks are private to that browser: they
are not sent anywhere, not shared between students, and not visible to anyone else.
Clearing site data, or opening the page on a different device, starts a fresh copy.

## A note on the example bullets

The example bullets under each task are illustrative. The percentages, prices and
figures in them are invented to demonstrate the structure of a Band 3 answer.
They are not model answers to be copied — submitted work must be the student's own.

## Authority

The OCR-set assignment is the authority on what each task requires. Where this page
and the brief disagree, the brief wins.
